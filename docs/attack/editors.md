# ReCut attack report — senior film editor + veteran fan editor

Tested build: `dist/` built 2026-10-04 07:19 from HEAD `cb94cdb` (working tree clean apart from `tests/`). Driven with Playwright under xvfb (1280×973 window), synthetic media from `scripts/make-test-media.sh … full` (60 s movies incl. HEVC / AC-3 / 5.1 variants, 30 s episodes, SRTs). Every finding below was reproduced in the running app unless marked *suspected*. Scratch scripts and screenshots: `/tmp/claude-0/-home-user-ReCut/db207bb1-8e4d-5534-84bf-420066a58686/scratchpad/attack-editors/` (scripts `s01`–`s08*.mjs`, logs `*.log`, screenshots in `shots/` — referenced below by file name).

## Verdict (10 lines)

1. The editing core is genuinely solid: every trim tool, ripple/roll/slip/slide, razor, Q/W/Ctrl+K, lift/extract, nudge and snapping are frame-exact and respect media handles; I assembled a 10-clip sequence from 3 sources with the keyboard alone and every in/out landed where it should.
2. The fan-edit layer is the real differentiator and it mostly works: match frame, Program SRC timecode, Inspector "Original source timecode", transcript search → load → insert with cues carried, character chips + Highlight/Solo/what-if, duplicate → Compare with structural diff, scene detection, Organize-as-Series.
3. The one thing that would make me put the app down on day one: after touching the Source monitor, clicking the Timeline does not make it the keyboard target — Space/JKL/Home/Up/Down/I/O keep driving the Source monitor (E-01). You cannot edit a 2-hour movie like this.
4. Three-point editing does not exist: timeline In/Out are ignored by `,` and `.`; edits always go to the playhead with the source duration (E-02). Premiere editors will mis-cut constantly.
5. Real fan-edit sources are HEVC/AC-3/DTS MKV rips; those import to a black Source with a wrong error ("Cannot decode h264" for an AC-3 problem) and a Program badge that says "Missing media", and no proxy is queued even with "Use proxies" on (E-03/E-07/E-08). Proxy generation itself is fast and works.
6. There is no out-of-sync indicator anywhere; Alt-drags and video-only ripple deletes silently desync audio (E-05). No audio meters anywhere (E-10).
7. Zoom-to-fit cannot show a 2-hour film (min zoom caps at ~100 min per screen) (E-06); otherwise a 126-clip / 2 h sequence stays responsive.
8. Several "where is this in my cut / in the original?" affordances stop one step short: transcript hits don't flag lines already on the timeline in project scope, continuity notes don't follow the clip they are linked to, double-clicking a timeline clip does nothing.
9. No P0: no crashes, no data loss; autosave, quit-confirm, relink and save/reopen all held up, and export is correct (disabled clips black, originals used, HEVC/AC-3 rendered).
10. Fix E-01..E-04 and the honest answer to "would I recut a trilogy in this?" flips from "no" to "yes, with grumbling"; the rest of the list is friction, not blockers.
