# ReCut UX attack — professional-NLE critique

Method: built app driven under xvfb with Playwright (`docs/attack/ux-shots/*.png`, 118 captures at 1200–2560 px wide), synthetic media from `scripts/make-test-media.sh`, plus DOM measurements (`getBoundingClientRect`, computed styles, `document.activeElement`) and WCAG contrast math on the theme tokens. Every finding below cites a screenshot I took and looked at; where a claim came from a DOM probe rather than pixels, the probe output is quoted.

## Verdict (10 lines)

1. The shell is genuinely Premiere-shaped: four workspaces, dockable tabbed zones, Source/Program/Timeline/Inspector in the right places, dense but legible 11–12 px type. A Premiere editor will recognise it in five seconds.
2. The single worst defect is in the shared `Dialog` primitive: every dialog (Rename, Tags, Speed, New Sequence, Sequence Settings, Preferences, Shortcuts, Export) gives initial focus to the title-bar Close (X) button. Enter therefore *cancels*, typing goes nowhere, and Ctrl+A inside a dialog field selects all timeline clips. This silently defeats every keyboard-first workflow.
3. "Which monitor gets Space?" is answered by a 1 px border going from `#3a3a3a` to `#4a4a4a` (1.28:1) and a 2 px tab underline. Clicking a monitor's picture gives no visible focus change at all.
4. Error states are better than most v1 NLEs: offline media gets a banner + Relink, HEVC gets a "Generate proxy" card, Program shows a MISSING MEDIA chip with a popover. But the timeline clip that *is* the HEVC problem carries no badge.
5. The timeline is readable at all three zoom extremes, drag ghosts/trim readouts are excellent, and the status bar's src/dur readout is editor-grade.
6. Hit targets are consistently under the 24 px pro-tool norm: track-header buttons are 18×16, tool buttons 18×18, splitters 4 px (10 px with the invisible halo).
7. The History/undo stack is polluted with eight "Probe media" entries after one import; a user who presses Ctrl+Z after importing undoes a probe, not an edit.
8. Panels degrade badly below ~260 px: Project toolbar wraps the proxies toggle label, Subtitles/Continuity rows truncate to "SEQU…", the source transport orphans one button onto a second row, and monitors can be collapsed to a 50 px strip with the Program picture gone entirely.
9. The "Audio" workspace is the Editing workspace with smaller monitors; there is no mixer, meter, or audio-specific panel, so the label over-promises.
10. Discoverability: Lift/Extract/Match Frame/Add Edit are reachable with tooltips or context menus; Ripple Trim (Q/W) exists only in the shortcuts dialog, and nothing in the UI teaches ,/./;/' to a newcomer beyond one empty-timeline hint.

### Things I tested that held up

- Escape closes every dialog, popover and context menu (`A15` → probe `export dialog still open after Escape: 0`; marker popover `after Escape popover count 0`).
- Space never leaks into text fields (`SPACE in search -> playing:false, val:"a b"`), and Delete in a search field does not delete clips (`clips before/after 3 3`).
- Timecode entry: click the Program TC, type `115`, Enter → playhead 115 (`C22-timecode-editing.png`).
- 10 video + 10 audio tracks and 203 clips render and scroll without layout breakage (`C41`–`C46`, `C44-200-clips-maximized.png`).
- Window resize 1200 → 2560 px keeps every zone intact; the Program bar hides Mute/Subtitles/Safe margins into the "…" menu at 1280 instead of wrapping (`D05-program-bar-1280.png`).

## What is good

- Workspace/zone system: tabbed zones, drag-to-move, "Show panel here" menu, per-workspace saved layouts, double-click-to-maximise, `Ctrl+`` ` restore (`A05-menu-zone-panel-menu.png`, `B83-timeline-maximized.png`).
- Drag ghosts and trim readouts are better than Premiere's: delta in frames + timecode + resulting start/duration, dashed ghost on both V and A tracks (`B26-drag-ghost-mid-drag.png`, `B27-trim-mid-drag.png`).
- Timeline status bar shows clip name, source range, duration, sequence position and a "+1 linked" badge — exactly what an assistant editor wants (`C54-crop-status-bar.png`).
- Error surfaces: offline banner with Relink, "Media offline" card with the full path, HEVC "Generate proxy" card, MISSING MEDIA chip with a popover that offers "Generate proxies (1)" (`B60`–`B64`).
- Inspector's ORIGINAL SOURCE TIMECODE block (orange 18 px, "at playhead"/"at clip start" mode, identity line) is the right headline for a fan-edit tool (`C55-crop-inspector-top.png`).
- Keyboard Shortcuts dialog: searchable, chips, conflict colouring, per-command add/remove, reset (`A10-dialog-shortcuts.png`).
- Export dialog: live SOURCE/OUTPUT summary, CHECKS list that blocks the button with a reason, FFmpeg command preview with Copy (`B50`, `B51`, `A15`).
- Compare workspace: A/B with sync lock, offset, STRUCTURE diff list with same/moved/trimmed/only-A/only-B legend (`B71-ws-Compare-AB.png`).
- Transcript search with Enter-to-load / Ctrl+Enter-to-insert hint and highlighted hits (`B72-panel-Transcript.png`).
- Native-feeling context menus with shortcut column, check marks, submenus, headings (`B30`, `B31`, `B34`).
- Timeline readability at 0.15, 2 and 12 px/frame: labels drop out gracefully, filmstrip thumbnails at high zoom (`B20`–`B22`).
