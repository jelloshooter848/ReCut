# Bug report archive

**Historical reports only. New bugs go to [GitHub Issues](https://github.com/jelloshooter848/ReCut/issues/new/choose)
(the Bug report template).** Link the issue from the fix PR with `Fixes #N`.

`closed/` holds the Markdown reports filed before the project moved to GitHub Issues (#148): one file per bug, with
the report, its verification and the fix. Code comments, tests and the changelog link to them, so they stay as they
are. Don't add new files here or edit the old ones.

The reports that were still open when the tracker was retired are now issues #154–#157.
